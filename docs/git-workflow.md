#Git Collaboration Workflow
##Workflow
1. Start from main.
2. Create a feature main.
3. Make changes.
4. Commit changes.
5. Push the feature branch.
6. Open a Pull Request.
7. Review changes.
8. Merge into main.
##Important commands
- git status
- git branch
- git switch -c
- git add
- git commit
- git push
- git pull
- git merge
##Beast practises
- use meaningful commit messages
- never commit secrets
- review changes before merging
- keep main stable
